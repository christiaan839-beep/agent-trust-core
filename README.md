# agent-trust-core

**Archived.** This repository holds no code. The trust core it was started for, where an agent can read and propose but
every change waits for the owner's yes and every action leaves a signed receipt, is built and maintained in
[sovereign-agents](https://github.com/christiaan839-beep/sovereign-agents), under `src/sovereign_agents/kit/`. The
receipts are checked with [verifiable-receipts](https://github.com/christiaan839-beep/verifiable-receipts).
